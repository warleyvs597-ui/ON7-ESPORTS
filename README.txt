ON7 ESPORTS — SITE CORRIGIDO COM OS ARQUIVOS ENVIADOS

A pasta assets contém:
- on7-logo.png: logo extraída da imagem da logo enviada, com fundo verde removido ao redor do emblema.
- on7-jogadores.png: imagem do elenco enviada, usada sem substituir os jogadores.
- camisa-oficial.jpg: imagem enviada da camisa, recortada para retirar parte da interface da captura.

Para testar: extraia o ZIP e abra index.html.
Para publicar no GitHub Pages: envie index.html, style.css, script.js e a pasta assets para a raiz do repositório; em Settings > Pages selecione Deploy from a branch, branch main e /(root).
